# 고사계 양식 도우미 (React Rewrite)

학사 일정(학년도·학기·고사명·시험일)과 시간표 자료(엑셀·PDF)를 기반으로 고사 운영 계획서, 가정통신문, 고사 원안 등 한글(hwpx) 고사계 공문 양식을 자동으로 변환·생성하는 도우미 웹 애플리케이션입니다.

## 주요 기능

1. **학사 일정 및 시험 변수 관리**
   - 학년도(스텝 조절 및 직접 입력), 학기, 고사명, 시험일 목록 관리
   - D-Day 및 고사 기간 자동 계산
   - 양식 문구 치환 규칙(추가 정보) 일괄 매핑

2. **HWPX 양식 및 시간표(엑셀·PDF) 업로드**
   - `.hwpx`, `.xlsx`, `.xlsm`, `.xls`, `.csv`, `.pdf` 드래그 앤 드롭 업로드
   - 6종 기본 내장 고사계 양식(운영 계획서, 학년별 가정통신문, 고사 원안) 탑재 및 복원 기능
   - 엑셀 및 PDF 파일로부터 시험 일정 및 시간표 자동 파싱

3. **고도화된 한글(HWPX) 자동 생성 및 채우기 엔진**
   - 시간표 데이터와 학년별 목록형 시간표, 등교 시각표, 시험범위표 자동 결합
   - 날짜 서식 자동 미믹(`mimic`: "10. 1.(목)" → "12. 8.(화)")
   - 다단 컬럼, 표 서식, 헤더·푸터, 이미지 등 충실한 문서 렌더링 및 미리보기
   - 1개 파일 직접 다운로드 및 다중 파일 일괄 ZIP 압축 다운로드

4. **양식별 규칙 및 표 직접 입력 모달**
   - 치환 규칙 편집(양식 문구 ↔ 바꿀 값, 날짜 프리셋)
   - 표 셀 직접 편집 및 스프레드시트 TSV 붙여넣기 지원
   - 텍스트 드래그 선택을 통한 즉시 치환 규칙 생성

## 기술 스택

- **프레임워크**: React 18, TypeScript, Vite
- **스타일링**: Tailwind CSS
- **파일 처리**: JSZip, XLSX, DOMParser/XMLSerializer
- **스토리지**: IndexedDB (대용량 HWPX 양식 및 시간표 영구 저장), LocalStorage (학사 일정 및 설정)
